# Model Selection with SVM (Support Vector Machine) Classifier

- **`gen_ms.jl`**  
  Generate synthetic data from promoter-switching models (1 on-state; 2–4 off-states).  
  *Output:* `tel_ntest.jld2`, `perm_ntest.jld2`, `perm1_ntest.jld2`, `perm2_ntest.jld2`
  *Output (ground-truth time data):* `tel_times.jld2`, `perm_times.jld2`, `perm1_times.jld2`, `perm2_times.jld2`

- **`dl_run_svm.jl`**  
  Apply the trained DART model (`ntrained_modelnb1_seed_1.bson`, generated by `dl_run_real.jl`) to the four promoter-switching models.  
  *Output:* `ntel_dlnb1_compare_seed_1`, `nperm_dlnb1_compare_seed_1`, `nperm1_dlnb1_compare_seed_1`, `nperm2_dlnb1_compare_seed_1`

- **`generate_svm_input.jl`**  
  Convert data into SVM-compatible format (ground-truth and DART-inferred promoter states).  
  *Output:*  
  - `true_rev2345.npz` (ground-truth)  
  - `ml_rev2345.npz` (DART)

The following python scripts were tested with Python 3.10.16, dependencies with versions are in listed in requirement.txt
- **`svm_true.py`**  
  Run SVM classification using ground-truth input.  
  *Output:* confusion matrix, ROC curve  

- **`svm_dart.py`**  
  Run SVM classification using DART-inferred input.  
  *Output:* figures of confusion matrix, ROC curve
