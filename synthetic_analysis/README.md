# Synthetic Data Analysis

This folder contains scripts for generating synthetic data, training the DART model, and evaluating its performance.

## Scripts

- `gen_ideal.jl` – Generate **idealized synthetic data**.
- `gen_real.jl` – Generate **realistic synthetic data**.
- `dl_run_ideal.jl` – Train and evaluate DART on **idealized data**.
- `dl_run_real.jl` – Train and evaluate DART on **realistic data** with lognormal distributed noise (cv denotes coefficient of variation):
  - `cv0` – 5% technical noise
  - `cv1` – 10% technical noise
  - `cv2` – 20% technical noise

## Data

All generated data is stored in the `synthetic_data` folder (generated synthetic data is in Zenodo: https://doi.org/10.5281/zenodo.DATASET_DOI)).

### `base_compare`
Binarized promoter-state results from different methods (HMM, MA, SG) at three burstiness levels.  
Example trace for Fig. 4B,C: `dl_eg_traces.jld2`.

### `ideal_data_res`
Idealized data used for DART and other binarization methods comparison:
- Files: high bursintess level: `genb_mtest.jld2`, intermediate level: `gennb1_mtest.jld2`, low level: `gennb0_mtest.jld2` (generated by `gen_ideal.jl`)
- DART models:
  - `mtrained_modelb33_seed_s`  
  - `mtrained_modelnb133_seed_s`  
  - `mtrained_modelnb033_seed_s`  
- DART test results:  
  - `mgen_dlb33_compare_seed_s`  
  - `mgen_dlb133_compare_seed_s`  
  - `mgen_dlb033_compare_seed_s`  
  *(s = 1,2,...,100)* 
- Hyperparameter tuning: change `33` → `333` 
> All results are obtained by running `dl_run_ideal.jl`.

### Realistic Data
Realistic data used for DART:

- `real_cv0_data_res` – cv0 (5% noise)
- `real_cv1_data_res` – cv1 (10% noise)
- `real_cv2_data_res` – cv2 (20% noise)

Each folder contains:

- **Synthetic data**  
  `genb_ntest_cvX.jld2`, `gennb1_ntest_cvX.jld2`, `gennb0_ntest_cvX.jld2`  
  *(generated by `gen_real.jl`)*

- **DART trained models**  
  - With noise: `ntrained_modelb_seed_1`, `ntrained_modelnb1_seed_1`, `ntrained_modelnb0_seed_1`  
  - Without noise: `mtrained_modelb_seed_1`, `mtrained_modelnb1_seed_1`, `mtrained_modelnb0_seed_1`

- **DART test results**  
  - With noise: `ngen_dlb_compare_seed_1`, `ngen_dlnb1_compare_seed_1`, `ngen_dlnb0_compare_seed_1`  
  - Without noise: `mgen_dlb_compare_seed_1`, `mgen_dlnb1_compare_seed_1`, `mgen_dlnb0_compare_seed_1`

> Note: `n` indicates results with added noise, while `m` indicates the noise-free case. All results are obtained by running `dl_run_real.jl`.
